## 中文

Mai C1 Edit + Thong 基于我们自己的 Mai C1 Edit，在原有 C1 造型上加入重新剪裁的 Thong。保留收窄后的胸前布料、调整后的前片和缩短的 Obi；Thong 前片收细，腰部衔接更平滑，保留原有腰部尺寸与后片轮廓。

提供 Pubic Hair（有毛）和 No Pubic Hair（无毛）两个版本。两者的服装与身体模型一致，仅附加毛发不同。每个 ZIP 都是独立安装包。

### 安装方法

1. 关闭游戏，选择一个版本并下载 ZIP。
2. 打开 Fluffy Mod Manager，选择 Street Fighter 6。
3. 添加 ZIP，启用对应 MOD。
4. 启动游戏，选择 Mai C1。

切换腿围、毛发或 Thong 组合前，先停用当前 Mai C1 MOD。

### 主要特点

- 保留 Mai C1 Edit 的胸前布料、前片与 Obi 调整。
- 加入重新剪裁的 Thong，前片收细，腰部过渡更平滑。
- 保留 Thong 原有腰部尺寸与后片轮廓。
- 提供有毛、无毛两个独立安装包。
- 沿用原有贴图与骨骼绑定。

### 使用要求

- PC 版 Street Fighter 6。
- 游戏中可使用 Mai。
- Fluffy Mod Manager。

## English

Mai C1 Edit + Thong builds on our Mai C1 Edit with a reshaped thong. It retains the narrower top panels, revised tare and shorter Obi. The thong has a slimmer front and smoother waist transitions, with the original waist fit and rear silhouette retained.

Two variants are available: Pubic Hair and No Pubic Hair. Both use the same clothing and body meshes; only the added hair differs. Each ZIP is a standalone package.

### Installation

1. Close the game and download one ZIP.
2. Open Fluffy Mod Manager and select Street Fighter 6.
3. Add the ZIP and enable the mod.
4. Launch the game and select Mai C1.

Disable the current Mai C1 mod before switching thickness, hair or thong options.

### Main features

- Retains the top-panel, tare and Obi edits from Mai C1 Edit.
- Adds a reshaped thong with a slimmer front and smoother waist transitions.
- Retains the original thong waist fit and rear silhouette.
- Separate Pubic Hair and No Pubic Hair packages.
- Original textures and skeletal bindings retained.

### Requirements

- Street Fighter 6 on PC.
- Access to Mai in-game.
- Fluffy Mod Manager.
